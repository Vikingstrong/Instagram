# Модерация эфиров: роли, мут, бан

Developer 2 (Claude Code), backend и frontend, поверх [эфиров](live-streams.md)
и [подарков](live-gifts.md). Требование владельца 2026-10-24: автор назначает
модераторов и ограничивает пользователей двумя уровнями — мут на время или
навсегда и полная блокировка, при которой эфиры автора скрыты, а
заблокированного выбрасывает из эфира на главную с надписью «Вас забанили на
трансляции». Решения ниже приняты Developer 2 соло и требуют review в PR.

## Решения

| Вопрос | Решение |
| --- | --- |
| Область | Роли и ограничения действуют на все эфиры автора, а не на один эфир |
| Роли | Автор (ведущий), модератор, зритель. Назначать и снимать модераторов может только автор |
| Кто ограничивает | Автор и его модераторы. Модератор не может ограничить автора или другого модератора; назначение модератором снимает его ограничения |
| Мут | Нельзя писать в чат и дарить подарки, смотреть можно. Сроки: 5 минут, 1 час, 24 часа или навсегда; снимается досрочно |
| Бан | Эфиры автора не показываются ни в списке, ни в профиле; прямой адрес отвечает `403 LIVE_BANNED`. Подключение закрывается сразу, комментарии забаненного в текущем эфире удаляются. Клиент уводит на главную с надписью «Вас забанили на трансляции» |
| Подписка | Бан не меняет подписку и доступ к постам: он только про эфиры |
| Хранение | `live_moderators (hostId, userId)` и `live_restrictions (hostId, userId, kind MUTE/BAN, until, createdById)`; истёкший мут не действует без фоновой очистки |

## API

- `GET/POST/DELETE /api/v1/lives/hosts/{hostId}/moderators[/{userId}]` — только автор.
- `GET /lives/hosts/{hostId}/restrictions`, `POST … { userId, kind: mute|ban, minutes: 5|60|1440|null }`,
  `DELETE …/{userId}/{kind}` — автор и модераторы.
- `Live.viewer`: роль текущего пользователя и срок его мута — в ответах
  `GET /lives/{id}`, join и heartbeat, чтобы интерфейс показал права.
- Ошибки: `LIVE_BANNED` 403, `LIVE_MUTED` 403, `LIVE_MODERATION_FORBIDDEN` 403.

## Web

- В чате и списке зрителей у автора и модераторов — меню по имени: мут
  (сроки), снять мут, заблокировать; автору ещё «назначить / снять модератора».
- Замьюченный видит заблокированное поле чата со сроком; подарки недоступны.
- Забаненный: сессия зрителя получает `LIVE_BANNED` или SSE-уведомление,
  закрывает соединение и уходит на главную, где показывается надпись.
- У автора на странице эфира — раздел «Модерация»: модераторы и ограничения
  с кнопками снятия.

## Проверки

- `live-moderation.integration-spec.ts`: только автор назначает и снимает модераторов; модератор мутит зрителя, но не автора и не другого модератора; неверный срок — 400; мут запрещает чат и подарки без списания, смотреть можно; истёкший мут не действует; мут навсегда и снятие; бан — SSE-уведомление, отключение, `LIVE_BANNED` на всех запросах эфира, удаление строк чата, скрытие из списка и профиля при подписке, действует на следующий эфир, снимается; назначение модератором снимает ограничения.
- `moderation.test.tsx`, `live.test.ts`: меню (сроки, бан, назначение только автором), отказ API в меню, поле замьюченного, надпись о бане один раз, остановка сессии зрителя при бане.
- `live-moderation.spec.mts` (desktop и mobile): автор назначает модератора, модератор мутит зрителя на 5 минут (поле и подарки скрыты), автор банит — зрителя уводит на главную с надписью «Вас забанили на трансляции», его строка исчезает у автора, эфир не виден в профиле; бан снимается в разделе «Модерация».
